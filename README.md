## 📌 Project Overview

This project focuses on cleaning and exploring a raw corporate dataset using Python libraries. It demonstrates the process of transforming messy data into a structured dataset and performing Exploratory Data Analysis (EDA) through visualizations.

## 🎯 Project Objectives

- Understand and inspect the raw corporate dataset.
- Identify and handle data quality issues.
- Clean and transform the dataset.
- Perform Exploratory Data Analysis.
- Explore data patterns and relationships through visualizations.

## 🛠️ Tools & Technologies

- **Python**
- **Pandas** – Data manipulation and cleaning
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical data visualization
- **Jupyter Notebook** – Analysis environment

## 🔄 Project Workflow

### 1. Raw Dataset
The original company dataset containing 10,000 records was used as the starting point for data inspection and cleaning.

### 2. Data Cleaning
The raw dataset was examined and processed to prepare a cleaned version for further analysis.

### 3. Cleaned Dataset
The processed dataset is available as `cleaned_company_data.csv`.

### 4. Exploratory Data Analysis
EDA and visualizations were performed in the Jupyter Notebook to explore the dataset and identify patterns.
